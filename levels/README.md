# Карты уровней

Каждый файл `*.txt` в этой папке — одна карта. Уровни идут по порядку
имён файлов: 01.txt — первый уровень, 02.txt — второй и т.д.
Если уровней больше, чем карт, карты повторяются по кругу
(враги при этом становятся сильнее).

Карты перечитываются при каждом старте игры из меню: нарисовали —
вышли в меню (GAME OVER → Enter, или перезапуск) — играете.

## Символы

```
  .   пусто
  #   кирпич (разрушается)
  @   сталь (пробивается только пулей с 3 звёздами)
  ~   вода (танки не проезжают, пули летят над ней)
  %   лес (танки и пули проходят; деревья поверх танков — можно спрятаться)
  -   лёд (танк игрока скользит, если отпустить кнопку)
```

## Размер — один из двух вариантов

```
  13 строк по 13 символов — «блоки»: один символ = клетка размером
                            с танк (как в оригинале). Проще рисовать.
  26 строк по 26 символов — «тайлы»: один символ = половина танка.
                            Для тонких стен и узких проходов.
```

## Прочее

  - Строки, начинающиеся с ';' — комментарии. Пустые строки пропускаются.
  - Штаб и кирпичная стена вокруг него ставятся автоматически
    (внизу по центру) — рисовать их не нужно.
  - Точки появления танков расчищаются автоматически:
      враги — левый верхний угол, центр верха, правый верхний угол;
      игроки — слева и справа от штаба.
  - Если в карте ошибка (не тот размер, неизвестный символ), игра
    напишет в консоль, где именно, и пропустит эту карту.
